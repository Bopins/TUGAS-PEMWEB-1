# Tugas Pemrograman Web — 8 Halaman HTML

## Cara menjalankan
Buka `index.html` di browser, atau gunakan Live Server pada VS Code.

## Halaman
profile.html, about-me.html, educations.html, course-schedule.html, hobbies.html, form.html, table1.html, table2.html. `index.html` adalah beranda tambahan.

## Publikasi GitHub Pages
1. Buat repository GitHub baru, misalnya `tugas-pemweb`.
2. Upload seluruh isi folder ini (termasuk folder assets) ke root repository.
3. Buka Settings > Pages > Build and deployment, pilih Deploy from a branch, branch main dan folder /(root), lalu Save.
4. Setelah deployment berhasil, URL umumnya `https://USERNAME.github.io/tugas-pemweb/`. Ganti USERNAME sesuai akun GitHub.

Catatan: data pendidikan merupakan contoh dari PDF dan dapat diedit. Foto profil menggunakan ilustrasi sementara. Form tidak mengirim data ke server.
